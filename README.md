# Генератор ветвей ASKO Invest — исходники

## Состав
- `asko-vetvi-generator.html` — генератор. Один файл без зависимостей: открыть двойным кликом в Chrome / Safari / Firefox, интернет не нужен (кроме шрифтов Manrope и IBM Plex Mono из Google Fonts; без сети интерфейс покажется системным шрифтом, на SVG это не влияет).
- `treelib.py` — та же геометрия на Python 3 (без зависимостей). Даёт байт-в-байт тот же рисунок, что генератор, при тех же параметрах и seed. Нужен для пакетной генерации (например, деревья для визиток всех сотрудников).

## Генератор
- Холст бесконечный: перетаскивание — сдвиг, колесо — масштаб, «Вписать» — показать дерево целиком.
- Экспорт берёт границы самого дерева + поле (параметр «Поле»).
- «Скачать SVG», «Скачать PNG» (масштаб 1×/2×/4×), «Копировать SVG».
- Настройки запоминаются в браузере (localStorage, ключ `asko-tree-v3`).
- Seed — номер дерева: одно число всегда даёт один и тот же рисунок.

## Пресеты (брендбук 3.0, режим «Листья»)
| Пресет | Назначение |
|---|---|
| Лист | Основной образ: обложки, билборды, первые экраны |
| Пара | Узкие и вертикальные форматы, сторис, ситилайты |
| Крона | Симметричные композиции: визитки, аватары, сувениры |
| Росток | Маленькие форматы и акценты рядом с текстом |
| Поток | Широкие фоны, паттерны, растяжки |
| Блокчейн | Цифровые активы: прямые углы и блоки, без света |

«Свет внутри изгиба» — параметры glow (яркость) и glowSize (глубина). В SVG свет сделан размытием (feGaussianBlur) с маской; Figma импортирует его как размытие слоя, при необходимости свет можно выключить и добавить вручную.

Значения пресетов — объект `PRESETS` в HTML и словарь `PRESETS` в `treelib.py`. Меняя пресет, правьте оба файла.

## Python
```python
import treelib as T
S = T.preset('Портфель', seed=417)          # пресет + переопределения
inner, box = T.build(S)                    # SVG-содержимое и границы [x0, y0, x1, y1]
x0, y0, x1, y1 = box; pad = 40
svg = (f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="{x0-pad} {y0-pad} {x1-x0+2*pad} {y1-y0+2*pad}">'
       f'{inner}</svg>')
open('tree-0417.svg', 'w').write(svg)
```
Основание ствола — точка (0, 0), дерево растёт вверх (в −y).
